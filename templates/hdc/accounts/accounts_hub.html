How It Fits Together — One Ledger, No Duplicates
Hub is only entry, sidebar cleaned

Every page reads and writes the same unified ledger (hdc_account_txn). Nothing stored twice, balances never disagree. Sidebar cleaned — only Hub, Manage, All Entries remain. All money handling via Hub.

  1. Record — smooth entry via Money Center (Direction → Type → Details) or CF Register. Each entry writes one document + its double-entry posting with overdraft block (minor units exact), duplicate guard, void sync.
  2. Other modules post too — payroll, purchases, expenses, subcontract, office, owner payments, tool rentals all write to same ledger automatically via _create_accounts_transaction_with_sync.
  3. Balances — Manage Accounts derives every balance from ledger (opening + in − out). Never stored, cannot drift.
  4. Review — Cash Flow daily report; All Entries audit view with receipts, void/restore, group_id splits.
  5. Close — Day Close (now in Hub) compares counted cash vs ledger, locks day. Locked day rejects back-dated entries, rolls counted closing forward.
