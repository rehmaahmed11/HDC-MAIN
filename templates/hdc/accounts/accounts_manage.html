{% extends "shared/base.html" %} {% block title %}Manage Accounts{% endblock %} {% block page_heading %}Manage Accounts{% endblock %} {% block content %} {# Manage Accounts — every account in one list. HDC port of the AMS `accounts/manage_accounts.html` view: a page header with the toolbar, gradient stat cards, the classification "group" chips, a filter bar, and one full-width table holding ALL accounts. Differences from AMS, and why: * AMS groups by a free-text `source_category`; HDC groups by the controlled Category → Subcategory hierarchy already in `hdc_account`, so the chips can never contain a typo'd group. * AMS stores `Account.balance` and mutates it on every post. HDC derives balances from the ledger, so the "Current" column here is always in step with the transactions page and can never drift. * AMS's Archived bucket is `is_active = false`. HDC has both `status` and `is_void`, so archived = voided, and the delete button archives instead of deleting whenever the account carries posted transactions. #} {# ── Page header ─────────────────────────────────────────────────────────── #}
